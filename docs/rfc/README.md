# OSS RFC Set

`docs/rfc/` is the public normative RFC surface for Tracehound OSS.

## Scope

This directory contains only RFCs that define one or more of:

1. OSS core invariants
2. Public runtime contracts
3. Adapter behavior
4. Deterministic operational guarantees
5. Implemented or implementation-bound OSS architecture

## Current Public Set

1. `RFC-0000` - Core architecture
2. `RFC-0009` - Coordination provider contract
3. `RFC-0010` - One-way membrane and trace ID signaling
4. `RFC-0011` - Pressure containment and graceful shielding
5. `RFC-0013` - Operational truth and Hound analysis
6. `RFC-0015` - External threat signal adapters (public draft)

## Exclusions

Enterprise fork proposals, pricing, packaging, market segmentation, and speculative commercial roadmap material are intentionally excluded from this directory.
